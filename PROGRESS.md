Fixed by moving the button's logic to a **document-level delegated click listener** registered inside `snippets/add-to-cart-recommendation.liquid` (already rendered unconditionally, once, via `layout/theme.liquid` on every real page load — guaranteed to actually execute, unlike anything living inside the conditionally AJAX-rendered drawer). On click: POST `/cart/add.js`, then fetch `/cart.js` to update the header cart bubble + dispatch `cart:lines-update`, then re-fetch `/?sections=cart-drawer-section` and swap `#shopify-section-cart-drawer-section`'s innerHTML — updates the whole drawer (line items, cross-sell, everything) in place with no page reload. `cart-drawer-cross-sell.liquid` itself now contains only the Liquid template/markup, no script.
